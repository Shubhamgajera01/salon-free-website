
# Phase 11 — Appointment Manager

Added a dedicated staff appointment workspace.

## Features
- Day-by-day appointment navigation
- Today button
- Customer search
- Status filter
- Men/Women/Kids filter
- Appointment counts
- Appointment details panel
- Confirm
- Complete
- Cancel
- Mobile responsive layout
- Supabase data when configured
- Local demo fallback

Open:
`admin-appointments.html`

## Production note
The dashboard relies on Supabase RLS from Phase 9. Keep the service-role key out of browser code.
