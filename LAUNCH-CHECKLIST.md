# Infinity The Family Salon — Launch Checklist

## Before going live
- Replace demo gallery images with approved salon photos.
- Verify exact salon name, address, phone and WhatsApp number.
- Confirm opening/closing hours.
- Replace demo service list/prices with the salon's final menu.
- Add verified Google Maps place URL.
- Add real customer reviews only with permission.
- Add official Instagram/Facebook links if available.
- Replace `https://example.com/` in the JSON-LD with the final domain.
- Test booking form on Android, iPhone and desktop.
- Connect booking requests to a real backend/WhatsApp/email workflow.
- Add favicon and final brand logo.
- Run an SEO/mobile/performance check before publishing.

## Important
The gallery currently uses remote demo imagery. It is intentionally marked as replaceable content and should not be presented as photographs of the actual salon until approved.
